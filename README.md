# Помощник по сбережениям

Интерактивная страница со стратегией AI-помощника по вкладам и счетам и кликабельным прототипом под iPhone 18 Pro Max.

Сборка: `./build.sh` собирает `index.html` (локальный просмотр, GitHub Pages) и `artifact.html` (публикация артефакта) из `parts/`.

Состав `parts/`:

- `00-head.html` стили и иконки, `10-hero.html` шапка и навигация
- `20-strategy-a.html` резюме, контекст, принципы, видение, сегменты, доверие
- `27-glance.html` дизайн для тех, кто не читает: правила, новые экраны, тапы, словарь
- `30-proto.html` кликабельный прототип, семь путей
- `40-strategy-b.html` точки входа, архитектура, движок
- `42-skills.html` каталог из 22 скиллов с экранами, `44-proactive.html` проактивные коммуникации и календарь
- `45-edge.html` сервис против ставки, `50-mcp.html` MCP и харнес, `60-plan.html` дорожная карта, метрики, риски, 90 дней
- `70–73-templates-*.html` экраны прототипа, `90-script.html` логика прототипа, каталога скиллов и ленты событий
