# Помощник по сбережениям

Две страницы об AI-помощнике по вкладам и счетам в Сбербанк Онлайн с кликабельным прототипом под iPhone 18 Pro Max в стиле Liquid Glass (стекло на слое управления и поверхностей, цветной фон за ним).

- `index.html` — полная стратегия: 24 раздела, восемь путей прототипа, 33 скилла, проактив, MCP, дорожная карта. Широкий взгляд.
- `pitch.html` — питч для руководства за 15 минут: 14 полноэкранных слайдов от рынка к одному сценарию и одному решению. На каждом слайде живой телефон, который сам проигрывает свою сцену по кругу (демо-режим); его можно остановить и листать руками. Клавиши: ← → слайды, P пауза демо, R демо сначала, F во весь экран, T тема.

- `archive/strategy-2026-10-15.html` — предыдущая версия стратегии: снимок до правок 16 октября 2026 (навигация из 24 ссылок, прежние цифры касаний и формулировка периметра). Из `parts/` не собирается, исходники той версии в истории git (коммит `d60e898`).

Сборка: `./build.sh` собирает из `parts/`:

- `index.html` и `pitch.html` — автономные страницы (локальный просмотр, GitHub Pages);
- `artifact.html` и `pitch-artifact.html` — сборки для публикации артефактом Claude (без doctype и head, ссылки из питча ведут на опубликованный артефакт стратегии, адрес задан в `build.sh`).

Состав `parts/`:

- `00-head.html` стили и иконки (общие для обеих страниц), `10-hero.html` шапка и навигация стратегии
- `20-strategy-a.html` резюме, контекст, принципы, видение, сегменты, доверие
- `27-glance.html` дизайн для тех, кто не читает: правила, новые экраны, тапы, словарь
- `30-proto.html` кликабельный прототип, восемь путей
- `40-strategy-b.html` точки входа, архитектура, движок; `41-rebalance.html` ребалансировка как процесс: уровни L1–L3, цепочки экранов, инварианты
- `42-skills.html` каталог из 33 скиллов с экранами, включая честные кросс-продажи «рядом со вкладом»
- `44-proactive.html` проактивные коммуникации: ритм, календарь, разрешения; `44-value.html` проактив ради ценности: бюджет внимания, ценность касания, копирайт от ценности
- `45-edge.html` сервис против ставки, `50-mcp.html` MCP и харнес, `60-plan.html` дорожная карта, метрики, риски, 90 дней
- `70–75-templates-*.html` экраны прототипа (`74` процесс ребалансировки, `75` ценность касаний и кросс-продажи), общие для обеих страниц
- `90-proto-core.html` ядро прототипа: пути, класс `Proto`, подгонка размера; экспортируется как `window.SavingsProto`
- `91-deck-script.html` логика стратегии: главный прототип, каталог скиллов, лента событий, процесс ребалансировки, калькуляторы
- `p10-pitch.html` стили и слайды питча; `p90-pitch-script.html` сцены демо, движок авто-демо (`Reel`), навигация по слайдам, калькулятор «ставка против утечек»

Сцена демо — список шагов: открыть экран (`id`), нажать элемент на текущем экране (`tap`, селектор; `id` как запасной вариант) или подержать подпись (`hold`). Нажатия идут через настоящий клик, поэтому шторки, Face ID и живые пересчёты работают как у пользователя.
